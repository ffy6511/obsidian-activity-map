# Activity Map 产品文档

本目录保存 Activity Map 的产品事实与用户体验要求。当前代码仅包含可构建的插件基础骨架，活动采集、统计查询和可视化能力仍需按照 Roadmap 分阶段实现。

## 文档导航

- [产品需求文档](PRD.md)：定义产品目标、指标口径、功能范围、交互规则和发布验收标准。
- [产品与数据决策](../specs/constitution/2026-07-21-activity-map-product-and-data.md)：定义跨版本保持稳定的数据、隐私与技术边界。
- [版本路线图](../specs/ROADMAP.md)：定义各版本交付结果和验收状态。
- [现有插件调研](../specs/research/2026-07-21-existing-plugin-landscape-research.md)：保存竞品、开源实现和技术证据。

## 文档职责

| 文档 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| PRD | 用户问题、产品能力、指标语义、完整交互、非功能要求、发布验收 | 调研过程、源码比较、实现任务清单 |
| Constitution | 稳定技术决策、数据不变量、持久化边界和失败语义 | 单次实现的文件清单和阶段任务 |
| Roadmap | 版本目标、可观察交付物、版本级验收 | 模块级实现步骤 |
| Active Spec | 当前实现增量、接口、阶段、测试与评审证据 | 重复陈述完整产品设计 |
| Research | 可复核证据、候选方案、实验和未决问题 | 未经批准的产品承诺 |

发生冲突时，先更新拥有该事实的上游文档，再同步下游 Roadmap、Spec、代码和 README。仓库内文档统一使用相对路径，便于迁移和独立审阅。
